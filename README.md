VLESS Manager
Интеллектуальное дополнение для приложения Podkop на OpenWrt. Позволяет удобно управлять подписками и автоматически выбирать самые быстрые серверы на основе реального пинга.
✨ Основные возможности
Мульти-подписки: Добавление нескольких ссылок на VLESS-конфиги через удобный динамический список в веб-интерфейсе.
Автопилот (Auto-Fastest): Интеллектуальный режим выбора сервера с минимальной задержкой. Система автоматически переключает Podkop на лучший узел.
Гибкое управление секциями: Индивидуальная настройка для каждой секции Podkop (MAIN, sec, tretiy). Для каждой можно выбрать:
Режим "Автоматически" (обновление по расписанию).
Принудительная фиксация конкретной локации из списка.
Глубокая интеграция: Полная встройка в LuCI интерфейс Podkop в виде отдельной вкладки.
Надежность: Все операции по записи конфигурации и перезапуску служб выполняются через безопасный RPC-мост с правами суперпользователя.
🛠 Технологический стек
Frontend: LuCI JavaScript API (совместимо с OpenWrt 23.05 / 25.12).
Backend: Shell-скрипты оптимизированные под архитектуру APK/APK-ADD.
Парсинг: Высокоскоростная обработка JSON через jq и sed.
Автоматизация: Системный планировщик cron.

Требования
Openwrt 25+
Установленный пакет luci-app-podkop (от ITDOG).
Наличие пакетов jq и curl (скрипт установки добавит их автоматически).
📂 Структура проекта
servers.js — Веб-интерфейс (LuCI View).
podkop-scanner — Скрипт загрузки и анализа серверов.
podkop-apply-node — Логика применения настроек.
podkop-autopilot — Фоновый процесс для расписания.
Установка:
curl -L -s -k "https://raw.githubusercontent.com/tokastro/vless-manager/main/install.sh" -o /tmp/install.sh && sh /tmp/install.sh
